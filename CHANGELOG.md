# История обновлений

## [1.0.14] — 23.09.2026

- Исправлено отображение заказа водителя: в каждом магазине показываются только позиции с фактическим количеством в заказе, а пустые магазины не выдаются.

## [1.0.13] — 23.09.2026

- Исправлена маршрутизация API рабочего места водителя при локальном запуске Reflex: запросы с frontend-порта теперь обращаются к backend-порту и получают JSON-ответы.

## [1.0.12] — 23.09.2026

- Добавлена авторизация администратора и безопасный вход водителя по персональному коду и PIN: PIN хранится как криптографический хеш, а доступ к назначенному заказу выдаётся только через серверную сессию.
- Добавлено мобильное PWA-рабочее место водителя: полный маршрутный заказ, выбор магазина, ввод фактического количества по каждой товарной строке, мгновенный пересчёт остатков и отметка выполненных точек.
- Добавлена офлайн-очередь операций, синхронизация после восстановления связи, защита от повторных отправок и безопасная очистка локальных данных при выходе.

## [1.0.11] — 16.09.2026

- Исправлена обработка заказов, где количества записаны текстом: значения вроде «20» и «1,5» теперь становятся числами и учитываются в итогах маршрутов.
- Добавлена интеграция GPS-трекеров ГдеМои: ключ API хранится локально, ID трекера задаётся у транспорта, а координаты подгружаются в реальные данные назначенного маршрута.
- Для почтовых накладных направления «Молоко» дополнены маркерами УПД Кировское—Торез, Горловка и Макеевка—Харцызск.

## [1.0.10] — 07.09.2026

- Добавлен раздел «Водители и транспорт»: локальный справочник с карточками водителей (рейтинг, телефон, транспорт по умолчанию, фото и документы) и транспорта (госномер, пробег), с проверкой уникальности и удалением с подтверждением.
- Перед обработкой заказа теперь открывается диалог назначения рейсов — водитель и транспорт выбираются из справочника отдельно для каждого активного маршрута, назначение сохраняется в истории заказа и не затрагивает общий список водителей маршрутов.
- Поля ввода и выпадающие списки переведены на единый вид без серых рамок: мягкая заливка вместо контура, подсветка при наведении и фокусе.

## [1.0.9] — 06.09.2026

- Веб-интерфейс переведён на новую светлую дизайн-систему по макету: Inter, единые Tabler Icons, общая палитра и компоненты без теней и градиентов.
- Навигация переделана в компактный адаптивный рельс с группами, хлебными крошками и вкладками; все прежние разделы остались доступны.
- Экран «Маршруты» теперь показывает все маршруты группами с поиском, сворачиванием, водителями и реальными статусами точек; добавление магазина встроено в таблицу.
- Во вкладке «Вес» можно напрямую вводить уже рассчитанный чистый вес и сверять загрузку с отгрузкой по магазинам и вечерней выгрузкой.
- Фоновые проверки почты и трекинга теперь завершаются после закрытия вкладки и не отправляют обновления отключённому клиенту.

## [1.0.8] — 04.09.2026

- Вкладка «Маршруты» переделана: список маршрутов теперь выпадающее меню вместо сетки карточек, и можно добавлять новые маршруты (до 8) кнопкой «+ Новый маршрут» — они сразу участвуют в раскраске заказа, GPS-трекинге и мобильной странице водителя.
- Боковое меню теперь закреплено на весь экран и остаётся на месте при прокрутке длинных страниц.
- Единый аккуратный вид скроллбаров вместо системных — во всём приложении, в светлой и тёмной теме.

## [1.0.7] — 04.09.2026

- Вкладка «Вес» переделана под ежедневную работу: три этапа (загрузка, выгрузка, отгрузка по магазинам), быстрый табличный ввод сразу многих позиций и автоподсказка наименований — из самого заказа и из истории ввода, с Tab для завершения слова.
- Формула изменена на грязный/чистый вес: если взвесили с ящиками, чистый вес = грязный вес − (кол-во ящиков × средний вес ящика).
- Список позиций заказа сворачивается по умолчанию — раньше он мог занимать весь экран на заказе с полусотней товаров.

## [1.0.6] — 03.09.2026

- Обновлён внешний вид дашборда по присланному дизайн-макету: сайдбар теперь всегда тёмный, не зависит от переключателя светлой/тёмной темы.
- Интерфейс сделан компактнее: уже сайдбар, меньше отступы и высота кнопок, компактнее карточки-статистики на Dashboard — на всех страницах.

## [1.0.5] — 02.09.2026

- Добавлена вкладка «OCR накладных» для выбора заказа и маршрута, загрузки фотографий и распознавания через Yandex Vision.
- Распознанные позиции можно проверить и отредактировать перед сохранением в журнале накладных.
- Добавлены локальное хранение фотографий, расчёт сумм и настройка Yandex Vision OCR в разделе «Настройки».

## [1.0.4] — 02.09.2026

- Добавлен чат-помощник — плавающая кнопка в правом нижнем углу на всех страницах, доступна любому, кто открыл сайт. Обычный диалог с Claude (Sonnet или Haiku на выбор), без доступа к заказам, весу или настройкам.
- Ключ Anthropic API (или подключение через Claude Code CLI без ключа) настраивается на странице «Настройки».

## [1.0.3] — 01.09.2026

- Добавлена вкладка «Вес» (веб-дашборд и tkinter): наименование, количество ящиков, средний и точный вес, привязка к заказу и маршруту, фильтры по заказу/маршруту, редактирование и удаление с подтверждением, подсказка веса по истории, итоговая сумма по списку.
- На странице «Заказы» можно задать водителя для каждого маршрута; имя показывается во вкладке «Вес» и в колонтитуле печатных листов маршрута («Маршрут №N (Водитель) - Район»).
- Добавлен `share_dashboard.bat` — временный доступ к дашборду с другого компьютера через Cloudflare Tunnel, без правки кода и без открытия портов на роутере.

## [1.0.2] — 31.08.2026

- Добавлен источник заказов Ольги Соленковой.
- Для накладных бухгалтера добавлены направления «Молоко», «Парус» и «Краймери» с распознаванием сначала по теме письма, затем по имени PDF.
- Добавлен фильтр «Без категории» для неопознанных PDF и писем без подходящего вложения.

## [1.0.1] — 30.08.2026

- Добавлен предварительный просмотр заказа перед созданием результата: режим, строки, совпадения, найденные магазины, объёмы, конфликты и неизвестные магазины.
- Обработка, лог и история теперь запускаются только после явного подтверждения просмотра.
- Изменение режима или загрузка нового файла сбрасывает устаревший просмотр.
- Исправлено отображение предлагаемых накладных: после выбора заказа из почты карточка накладных открывается автоматически.

## [1.0.0] — 29.08.2026

- Добавлена обработка книг Excel в форматах `.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.xltx` и `.xltm`.
- Для бинарных форматов результат конвертируется в обычный `.xlsx` без переноса VBA.
- История обработки и объём по маршрутам объединены для консольной версии, tkinter и веб-дашборда.
- Повторная обработка одного заказа обновляет его статистику, не удваивая объём.
- Добавлены почтовый watcher, привязка накладных и страница трекинга.
- Добавлен запуск проекта на новом компьютере через проверяемый `start_dashboard.bat`.
