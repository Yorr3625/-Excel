# История обновлений

## [1.0.6] — 03.09.2026

- Обновлён внешний вид дашборда по присланному дизайн-макету: сайдбар теперь всегда тёмный, не зависит от переключателя светлой/тёмной темы.
- Интерфейс сделан компактнее: уже сайдбар, меньше отступы и высота кнопок, компактнее карточки-статистики на Dashboard — на всех страницах.

## [1.0.5] — 02.09.2026

- Добавлена вкладка «OCR накладных» для выбора заказа и маршрута, загрузки фотографий и распознавания через Yandex Vision.
- Распознанные позиции можно проверить и отредактировать перед сохранением в журнале накладных.
- Добавлены локальное хранение фотографий, расчёт сумм и настройка Yandex Vision OCR в разделе «Настройки».

## [1.0.4] — 02.09.2026

- Добавлен чат-помощник — плавающая кнопка в правом нижнем углу на всех страницах, доступна любому, кто открыл сайт. Обычный диалог с Claude (Sonnet или Haiku на выбор), без доступа к заказам, весу или настройкам.
- Ключ Anthropic API (или подключение через Claude Code CLI без ключа) настраивается на странице «Настройки».

## [1.0.3] — 01.09.2026

- Добавлена вкладка «Вес» (веб-дашборд и tkinter): наименование, количество ящиков, средний и точный вес, привязка к заказу и маршруту, фильтры по заказу/маршруту, редактирование и удаление с подтверждением, подсказка веса по истории, итоговая сумма по списку.
- На странице «Заказы» можно задать водителя для каждого маршрута; имя показывается во вкладке «Вес» и в колонтитуле печатных листов маршрута («Маршрут №N (Водитель) - Район»).
- Добавлен `share_dashboard.bat` — временный доступ к дашборду с другого компьютера через Cloudflare Tunnel, без правки кода и без открытия портов на роутере.

## [1.0.2] — 31.08.2026

- Добавлен источник заказов Ольги Соленковой.
- Для накладных бухгалтера добавлены направления «Молоко», «Парус» и «Краймери» с распознаванием сначала по теме письма, затем по имени PDF.
- Добавлен фильтр «Без категории» для неопознанных PDF и писем без подходящего вложения.

## [1.0.1] — 30.08.2026

- Добавлен предварительный просмотр заказа перед созданием результата: режим, строки, совпадения, найденные магазины, объёмы, конфликты и неизвестные магазины.
- Обработка, лог и история теперь запускаются только после явного подтверждения просмотра.
- Изменение режима или загрузка нового файла сбрасывает устаревший просмотр.
- Исправлено отображение предлагаемых накладных: после выбора заказа из почты карточка накладных открывается автоматически.

## [1.0.0] — 29.08.2026

- Добавлена обработка книг Excel в форматах `.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.xltx` и `.xltm`.
- Для бинарных форматов результат конвертируется в обычный `.xlsx` без переноса VBA.
- История обработки и объём по маршрутам объединены для консольной версии, tkinter и веб-дашборда.
- Повторная обработка одного заказа обновляет его статистику, не удваивая объём.
- Добавлены почтовый watcher, привязка накладных и страница трекинга.
- Добавлен запуск проекта на новом компьютере через проверяемый `start_dashboard.bat`.
