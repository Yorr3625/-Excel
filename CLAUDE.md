# Работа с проектом

Локальное Python-приложение обрабатывает Excel без LLM/API. Токены расходуются только при работе ассистента с репозиторием.

## Экономия контекста

- Для обзора используй `git ls-files`; ищи только в `modules/`, `orders_dashboard/`, `tests/` и нужных корневых файлах.
- Не сканируй `.git/`, `.venv/`, `.web/`, `data/`, кэши и результаты сборки.
- Большие `orders_dashboard/orders_dashboard.py` и `README.md` читай точечно: поиск символа, затем нужный диапазон строк.
- Не читай рабочие книги, логи, почтовые кэши и `config/mail.json` без прямой необходимости.
- Для малой правки сначала запускай прицельный тест, полный `python -m pytest` — перед завершением при изменении кода.

## Карта

- `modules/pipeline.py` — цикл обработки; `excel_io.py` — форматы и загрузка Excel.
- `excel_cleaner.py`, `route_finder.py`, `route_sheets.py` — преобразование книги и маршруты.
- `history.py` — история и объёмы; `mail_watcher.py` — почта и накладные.
- `gui_app.py` — Tkinter; `orders_dashboard/orders_dashboard.py` — Reflex; `tests/` — pytest.

## Инварианты

- `.xls`/`.xlsb` открываются через `excel_io`; результат всегда `.xlsx`, без переноса VBA.
- Повторная обработка файла не должна удваивать статистику.
- Не меняй бизнес-логику или статистику без явного запроса.
- Перед завершением проверь `git diff --check`, `git diff --stat` и `git status --short`.
